# 一页纸 · 每天过一遍

把《27 考研政治一页纸 · 知识点手册》做成每天一小时能过完一遍的网页。

双击 **打开.command** 就能用。

---

## 它做了什么

原书 35 页、100 个知识点。PDF 里每个字的颜色都是作者标出来的重点层级：

| 颜色 | 含义 |
| --- | --- |
| 灰 | 过渡文字，扫过去就行 |
| 紫蓝 | 关键考点 |
| 红 | 核心答案 |
| 橙 | 结果 / 结论 |
| 天蓝 | 线索 |
| 深蓝 | 史纲专项 |
| 紫 | 口诀 |

这个网页把每个字连颜色一起搬了过来（不是截图，是真文字），所以：

- **顺序过**：照原书版式读，彩色词就是重点，灰字自动弱化
- **遮色自测**：彩色词全部遮住，只剩灰字当提示 —— 直接测「这个空该填什么」。点一下揭一块
- **目录**：100 点按 马原 / 史纲 / 其他 分组，标出记住的和没记住的

## 一小时怎么保证

不是每张卡都花一样的时间。网页按每张卡的字数和彩色词密度算时长：
会议大观下（98 行）确实要 4 分钟，人的本质只要 5 秒。

长卡会切成「1/12」这种多屏，一屏不超过一屏高度（不会让你滚半天），
所以 100 个知识点变成约 150–230 屏，一屏 20 秒上下。

顶部那根进度条有两个标记：
- 棕色填充 = 实际用了多久
- 红色竖线 = 按配速**现在应该**到哪

落在红线附近就是正好，落后会提示「慢 X 分」。

## 键位

| 键 | 作用 |
| --- | --- |
| `→` `空格` `j` | 下一屏 |
| `←` `k` | 上一屏 |
| `1` | 顺序过 |
| `2` | 遮色自测 |
| `3` | 目录 |
| `A` | 全揭开 |
| `R` | 全遮回 |
| `?` | 提示 |

每张卡右上角三个按钮：⚑ 标记、✕ 没记住、✓ 记住。
「只看没记牢的」（顶部 ⚑）会筛出 ✕ 和标了 ⚑ 的，第二天专门过这些。

## 进度存在哪

浏览器 localStorage，不上传任何地方。换浏览器、清缓存会丢。
想跨设备用同一个进度，得自己同步 `yyz.progress.v1` 这个键的值。

设置里可以改：时间预算（45/60/75/90 分钟）、正文字号、遮色强度、是否遮成实心色块。

## 文件

```
index.html      页面
style.css       样式（配色取自原书）
app.js          逻辑（分段、配速、自测、进度）
data.js         知识点数据（100 卡，逐字带颜色）
icons/          原书里的 ✅ ❌ ① ② ⚑ 等图标，从 PDF 里原样抽出
img/            原书史纲整体脉络图
source/         原始 PDF（备份，网页不用它）
```

## 它不做什么

- 不联网，不发请求
- 不替你判断「记住了没有」—— 遮色揭不揭得开，你自己看得见
- 原书是《27 考研政治一页纸》知识点手册，作者澄潇宇；这个网页只是把它做成方便每天翻的形式，内容一字未改

## 内容怎么来的

用 PDFKit 逐字提取：每个字符的坐标、颜色、字号，
再按 y 坐标分行、按 x 分栏，识别「知识点 NNN」+ 标题作为卡片边界，
同编号跨栏/跨页的续排合并成一张卡。
图标是 PDF 内嵌的 192×192 位图，按绘制位置还原到行首或行中。
最后做了一次全文字符集比对，确认没有丢字（只去掉了页眉页脚和「知识点 NNN」标签本身）。
