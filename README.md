# 一页纸 · 每天过一遍

把《27 考研政治一页纸 · 知识点手册》做成每天一小时能过完一遍的网页。

双击 **打开.command** 就能用。

---

## 它做了什么

原书 35 页、100 个知识点。PDF 里每个字的颜色都是作者标出来的重点层级：

| 颜色 | 含义 |
| --- | --- |
| 灰 | 过渡文字，扫过去就行 |
| 紫蓝 | 关键考点 |
| 红 | 核心答案 |
| 橙 | 结果 / 结论 |
| 天蓝 | 线索 |
| 深蓝 | 史纲专项 |
| 紫 | 口诀 |

这个网页把每个字连颜色一起搬了过来（不是截图，是真文字），所以：

- **顺序过**：照原书版式读，彩色词就是重点，灰字自动弱化
- **遮色自测**：彩色词全部遮住，只剩灰字当提示 —— 直接测「这个空该填什么」。点一下揭一块
- **目录**：100 点按 马原 / 史纲 / 其他 分组，标出记住的和没记住的
- **题库**：2010–2026 十七套真题，646 道，能做题、判分、记错题，并挂回知识点

## 题库

数据来源：你给的三份 PDF。

| 来源 | 内容 | 用法 |
| --- | --- | --- |
| 考研政治 10-25 真题完整版+答案 | 2010–2025 十六套，每年 16 单选 + 17 多选 + 5 分析，附官方答案与答案要点 | 全部入库，答案一律取自原书答案区 |
| 2026 考研政治真题 | 2026 一套，只有试题 | 入库，标「原卷无答案」，做题时不算对错 |
| 27 考研政治一页纸 | 100 张知识卡 | 已有部分 |

一共 **646 题**：272 单选、289 多选、85 分析题。

### 四个视图

- **套卷**：按年份刷整套，题号条标出对错，跳题随意
- **题库检索**：按题干/选项/题号搜，也能按学科、题型筛
- **错题本**：答错的自动进来，能一键导出成文本贴进墨墨
- **知识点回查**：100 张卡各自挂了多少题、挂的是哪几题

### 题目和知识点怎么对上

原书没有给「哪题对应哪张卡」，所以我用文本相似度自动挂：

1. **学科锁死**：马原题只挂马原卡，史纲题只挂史纲卡，毛中特/思修只挂「其他」那 6 张口诀卡
2. **打分为 2-gram + 4-gram**，4-gram 权重更高（术语精确重合），2-gram 补软匹配
3. **IDF 压噪**：「社会主义」「中国共产党」这类到处都有的词权重自然变低
4. **阈值**：马原/史纲 0.045，毛中特/思修 0.055，时政 0.10（时政题跨界，宁缺勿滥）

结果：**213 题挂上了卡，79 张卡有题**。挂上的会在卡片底部显示「做过这些真题 → 2019-1 2021-1」，
点进去直接跳到那道题；题目页底下也有「回到知识点 002」跳回来。

剩下 433 题没挂 —— 主要是毛中特（156 题）和这本周册覆盖不到的范围，硬挂会误导，所以留白。
点「翻马原的卡 →」可以按学科手动翻。

### 数据自检

`tools/build_questions.py` 每次生成都会跑一遍校验：
题干长度、选项数是否 4 个、有没有空选项、单选是不是单答案、多选是不是至少两个答案。

唯一一条已知缺陷：**2012 年第 17 题原书漏印答案**（原 PDF 答案区从 18 开始），
网页里标成「原卷未给出答案」，不猜。


## 一小时怎么保证

不是每张卡都花一样的时间。网页按每张卡的字数和彩色词密度算时长：
会议大观下（98 行）确实要 4 分钟，人的本质只要 5 秒。

长卡会切成「1/12」这种多屏，一屏不超过一屏高度（不会让你滚半天），
所以 100 个知识点变成约 150–230 屏，一屏 20 秒上下。

顶部那根进度条有两个标记：
- 棕色填充 = 实际用了多久
- 红色竖线 = 按配速**现在应该**到哪

落在红线附近就是正好，落后会提示「慢 X 分」。

## 键位

| 键 | 作用 |
| --- | --- |
| `→` `空格` `j` | 下一屏 |
| `←` `k` | 上一屏 |
| `1` | 顺序过 |
| `2` | 遮色自测 |
| `3` | 目录 |
| `4` | 题库 |
| `A` | 全揭开 |
| `R` | 全遮回 |
| `?` | 提示 |

题库里：`→` `←` 翻题，`回车` 交卷。

每张卡右上角三个按钮：⚑ 标记、✕ 没记住、✓ 记住。
「只看没记牢的」（顶部 ⚑）会筛出 ✕ 和标了 ⚑ 的，第二天专门过这些。

## 进度存在哪

浏览器 localStorage，不上传任何地方。换浏览器、清缓存会丢。
想跨设备用同一个进度，得自己同步 `yyz.progress.v1` 这个键的值。

题库的作答单独存三个键：
`yyz.ans.v1`（每题选了什么）、`yyz.wrong.v1`（错题）、`yyz.quiz.v1`（每套做到第几题）。

设置里可以改：时间预算（45/60/75/90 分钟）、正文字号、遮色强度、是否遮成实心色块。

## 它不做什么

- 不联网，不发请求
- 不替你判断「记住了没有」—— 遮色揭不揭得开，你自己看得见
- 不判断分析题答得好不好 —— 分析题只给「答案要点」，自己对着看
- 原书是《27 考研政治一页纸》知识点手册，作者澄潇宇；这个网页只是把它做成方便每天翻的形式，内容一字未改
- 真题来自公开的历年试题与答案解析，只做本地复习用，不转载分发

## 内容怎么来的

用 PDFKit 逐字提取：每个字符的坐标、颜色、字号，
再按 y 坐标分行、按 x 分栏，识别「知识点 NNN」+ 标题作为卡片边界，
同编号跨栏/跨页的续排合并成一张卡。
图标是 PDF 内嵌的 192×192 位图，按绘制位置还原到行首或行中。
最后做了一次全文字符集比对，确认没有丢字（只去掉了页眉页脚和「知识点 NNN」标签本身）。
